# Wikimedia Commons vault

Wikimedia Commons is the single biggest free-license media library on the web -
individual files carry tags like CC0, public domain, CC BY, or CC BY-SA, shown next to
every file. Start from the categories below, or use Commons search and filter by
license. Attribution-friendly by design, and every page tells you exactly what you can
do.

| Source | What's inside | License notes | Safe to sell | Link |
|--------|---------------|---------------|--------------|------|
